# Maintainers

The people with commit access, who review and merge pull requests and cut
releases. See [GOVERNANCE.md](GOVERNANCE.md) for what that involves and how the
list changes.

| Maintainer | GitHub                                 | Areas      |
| ---------- | -------------------------------------- | ---------- |
| Luca       | [@lucabmn](https://github.com/lucabmn) | everything |

This is also the list [`.github/CODEOWNERS`](.github/CODEOWNERS) draws on — a
pull request touching anything in this repository requests a review from it
automatically.

## Reaching a maintainer privately

- **Security vulnerabilities:** do not use email or a public issue. Use the
  private advisory flow in [SECURITY.md](SECURITY.md).
- **Code of Conduct reports:** contact any maintainer above. If the report
  concerns a maintainer, contact a different one; where there is only one, the
  Contributor Covenant's own escalation path applies.

## Emeritus

None yet. Maintainers who step back — or who have been inactive for a year —
are listed here rather than removed. It is bookkeeping, not a judgement, and it
reverses on request.
